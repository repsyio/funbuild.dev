# AGENTS.md

Shared instructions for coding agents working in this repository.

## Pull request descriptions

Write pull request descriptions in clear Markdown with consistent sections:

- `## Summary`: one short paragraph explaining the user-facing or operational outcome.
- `## Changes`: a concise bullet list of the material implementation changes.
- `## Verification`: the checks and tests that were actually run, using fenced code blocks for commands when useful.
- `## Issue`: link or reference the related issue, when applicable.

Keep the description scannable, use complete sentences, avoid raw tool output, and do not claim checks passed unless they were run successfully. Update the existing description when new commits materially change the scope or verification results.
